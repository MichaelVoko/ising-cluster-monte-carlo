My Part II Physics Computational Project for which I was awarded the Corpus Christi College Project Prize for a high First-Class result. 

Comparison between the Metropolis-Hastings, Wolff and Swendsen-Wang Algorithms on the 2D Ising Model.

Structure
- report.ipynb : Main report
- Simlation_module.py : Simulation code
- Analysis_module.py : Analysis code (autocorrelation time and time per step)
- Algorithm_module.py : Algorithm implementation
- load-final.ipynb: Used to run all simulations (with worker.py as well)
- cache : Saved simulation data
- All other files are for plot generation (to clean up report notebook)
